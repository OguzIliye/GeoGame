# GeoGame

Poligon tabanlı dünya haritası üzerinden oynanan, mid-resolution pixel art bölgesel strateji web oyunu.

## Çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda açılan adresten (varsayılan `http://localhost:5173`) dünya haritasındaki herhangi bir ülkeye tıklayarak oyuna başlayabilirsiniz.

## Test ve Üretim Derlemesi

```bash
npm test
npm run build
```

Tasarım detayları için [DESIGN.md](DESIGN.md), geliştirme fazları için [PROGRESS.md](PROGRESS.md) dosyalarına bakabilirsiniz.
