# Pixel World (GeoGame)

Poligon tabanlı dünya haritası üzerinden oynanan, mid-resolution pixel art bölgesel strateji web oyunu.

## Çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda açılan adresten (varsayılan `http://localhost:5173`) **Pixel World** ana ekranından **Tutorial**'ı inceleyebilir veya **Oyna** diyerek dünya haritasından ülkenizi seçip oyuna başlayabilirsiniz.

## Test ve Üretim Derlemesi

```bash
npm test
npm run build
```
